# レビュー記録

このディレクトリには、現行の実装・設計に対するレビュー結果を保存します。レビューは課題や改善案を記録する資料であり、機能仕様の正本ではありません。現行仕様は対象コードと `../design/` を確認してください。

- 直下: 現行のレビュー記録
- [archive/](archive/): 過去のレビュー記録

新しいレビューは、`review_YYYY_MM_DD_<topic>.md` の形式でこのディレクトリに追加します。現行性を失った資料は `archive/` へ移動します。
