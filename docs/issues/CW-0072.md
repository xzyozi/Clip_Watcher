# [CW-0072] [architecture] ContextMenuMixin における汎用 UI コンポーネントとグローバルアプリケーションインスタンスの過度な密結合

## 1. 概要・背景
汎用テキスト入力ウィジェットの基底 Mixin が、全機能を持つ app インスタンスを必須とし、多言語化やイベントディスパッチャと直接密結合している。

### 課題詳細 (Problem Detail)
CustomEntry や CustomText のベースとなる ContextMenuMixin は、Entry や Text に右クリックメニュー（Cut, Copy, Paste, Select All）を追加する汎用 UI コンポーネントである。しかし、__init__ で app インスタンスを必須とし（if not app or not hasattr(app, 'translator'): raise ValueError(...)）、self.app.event_dispatcher.subscribe('LANGUAGE_CHANGED', self._rebuild_menu) への登録・解除など、アプリケーション全体のコンテナと強く結合している。単なるテキストボックス部品であるにもかかわらず、単体テスト時や他プロジェクトでの再利用時にも BaseApplication（および event_dispatcher, translator）の完全なモックまたは実体が必要となり、テスト容易性と部品としての独立性を著しく阻害している。
