# [CW-0073] [bug] macOS環境において起動時にウィンドウが黒画面になりGUIウィジェットが正常に描画されない

## 0. メタ情報 (Scope & Impact)
- **検出テーマ**: プラットフォーム互換性・GUIレンダリング（macOS）
- **重要度**: High
- **関連Issue**: #153
- **起票ステータス**: `stage:ready`

## 1. 概要・背景
macOS 環境にて `python clip_watcher.py` を実行すると、ウィンドウ自体は生成されて起動するものの、ウィンドウ内部が黒一色（ダークグレー単色）となり、タブやテキスト、履歴リストなどのウィジェットが視認できない状態となる。

### 課題詳細 (Problem Detail)
1. **`ThemeManager` による `aqua` テーマの強制解除（主因）**:
   - `src/gui/theme_manager.py` の `apply_theme()` において、プラットフォームに関わらず `style.theme_use("clam")` または `style.theme_use("default")` が無条件に実行されていた。
   - macOS の Tkinter (Tk 8.6) は Cocoa ネイティブの `aqua` テーマを前提としており、`clam` や `default` テーマへ切り替えると Cocoa レイヤー（CALayer）と Tk 描画サーフェスの同期が崩れ、ウィンドウ内部が黒一色のままウィジェットが描画されない。
2. **`CustomEntry` (`tk.Entry`) のスタイル適用欠落（入力欄黒潰れの要因）**:
   - `src/gui/theme_manager.py` の `apply_theme_to_widget_tree()` において、`tk.Text` や `tk.Button` などは背景色・文字色が適用されているものの、`tk.Entry`（`CustomEntry`）の処理が完全に欠落していた。
   - その結果、検索バー（`Search:`）の背景がデフォルトの黒色となり、入力テキストが完全に不可視となる黒潰れが発生していた。
3. **`tk.PanedWindow` の背景色追従漏れ**:
   - `ttk.Notebook` 内の `tk.PanedWindow` がテーマ変更時に背景色更新されず、ペイン境界の描画が乱れる要因となっていた。
4. **OS ダークモードとアプリ側 Light テーマの不整合（キメラ描画・文字消失の決定打）**:
   - macOS のシステム設定が「ダークモード」の場合、`aqua` テーマは Cocoa のシステムアピアランスに従いウィンドウや親フレームを自動的にダーク色（`#323232` 等）で強制描画する（Python側から白く上書き不可）。
   - 一方でアプリ側が初期設定の `theme = "light"` のままだと、`tk.Text` や `tk.Entry` は真っ白に塗りつぶされ、`TLabel` や `TButton` には暗い文字色が設定されるため、ダークな親背景の上で文字が完全消失するキメラ状態（視認性ゼロ）が発生する。

## 2. 仕様および要求事項 (修正方針)
- [x] **案 1 (推奨)**:
  1. `src/gui/theme_manager.py` の `apply_theme()` において、`sys.platform == "darwin"` かつ `"aqua" in style.theme_names()` の場合は `style.theme_use("aqua")` を維持する。
  2. `apply_theme_to_widget_tree()` に `isinstance(widget, tk.Entry)`（背景色 `entry_bg`、文字色 `entry_fg`、選択色、カーソル色 `insertbackground`）の処理を追加する。
  3. `apply_theme_to_widget_tree()` に `isinstance(widget, tk.PanedWindow)`（背景色 `frame_bg`）の処理を追加する。
  4. macOS 環境において OS のシステム外観（Dark / Light）を検知（`defaults read -g AppleInterfaceStyle`）するユーティリティを導入し、macOS 上では OS の外観に調和したテーマ（Dark / Light）を自動連動させてキメラ描画・文字消失を防止する。

## 3. 段階的実装手順 (Step-by-step Execution)

## 5. ドメイン知識・技術上の落とし穴 (Domain Knowledge & Technical Pitfalls)
- macOS Tkinter では Cocoa との統合の観点から `aqua` テーマが基本となる。X11 向けテーマ（`clam` 等）を無理に適用すると描画パイプラインが破損する。
- `CustomEntry` は `tk.Entry` を継承しているため、`ttk.Style` ではなく `widget.config(...)` による直接色設定が不可欠である。
