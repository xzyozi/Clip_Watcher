# [CW-0038] [security] clipboard_monitor におけるプロセス名比較の大文字小文字不一致によるパスワードマネージャー除外バイパス

## 0. メタ情報 (Scope & Impact)
- **検出テーマ**: セキュリティ
- **重要度**: High
- **関連Issue**: 該当なし
- **起票ステータス**: `stage:ideation` (agys 自律レビュー起票)

## 1. 概要・背景
除外対象アプリのプロセス名比較が大文字小文字を区別して行われているため、KeePassやBitwarden等のパスワードマネージャーからコピーした認証情報が除外されずに履歴DBへ保存される。

### 課題詳細 (Problem Detail)
src/core/config/defaults.py の DEFAULT_USER_SETTINGS では excluded_apps に小文字（keepass.exe, bitwarden.exe）が登録されている一方、Windows の GetModuleBaseNameA は実行ファイルの実体ケース（例: KeePass.exe, Bitwarden.exe）を返します。clipboard_monitor.py の _update_history_with_new_entry 内で if active_process in self.excluded_apps: と完全一致で比較しているため判定が False となり、パスワードマネージャーからコピーしたマスターパスワードや機微なトークンが除外されず、プレーンテキストとして履歴DBに永続化される脆弱性があります。
