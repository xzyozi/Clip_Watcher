# [CW-0043] [edge_cases] template_renderer における None 値および不正データ型に対する防御処理の欠落による TypeError / 文字列化バグ

## 0. メタ情報 (Scope & Impact)
- **検出テーマ**: エッジケース処理
- **重要度**: Medium
- **関連Issue**: 該当なし
- **起票ステータス**: `stage:ideation` (agys 自律レビュー起票)

## 1. 概要・背景
テンプレート定義の body や variables の各値が None の場合に TypeError が発生するか、文字列 "None" が意図せず埋め込まれる。

### 課題詳細 (Problem Detail)
TemplateRenderer.render において複数の None に対する防御が欠落しています。1) variables['input'] が None の場合に str(None) により "None" という文字列が出力される、2) template_def.get("body") の値が None（明示的に null が設定された場合）のときに re.sub で `TypeError: expected string or bytes-like object, got 'NoneType'` が発生する、3) template_def.get("variables") が None の場合に for ループで `TypeError: 'NoneType' object is not iterable` が発生する、4) full_vars 内の変数値が None の場合に replace_match 内で str(None) によりテンプレートへ "None" が埋め込まれる、など予期せぬ描画結果やクラッシュの原因となります。
