# [CW-0037] [feat] 複数行・危険コマンドのコピー前に警告する

## 背景

端末マルチプレクサやターミナルへクリップボード内容を貼り付ける際、複数行のシェルコマンドや破壊的な操作を意図せず実行する危険がある。

Clip Watcherの履歴を経由してコピーする場合に、リスクのある内容を可視化し、ユーザーが確認してからコピーできるようにしたい。

## 目的

クリップボード履歴のテキストを分析し、複数行または危険性の高いシェル構文を検出した場合、理由を表示して明示確認を求める。

本機能はコマンドを実行せず、ユーザー操作を自動で妨げない。外部アプリケーションの貼り付け操作をグローバルにフック・遮断しない。

## 対象範囲

- Clip Watcherの履歴一覧・詳細・コピー操作における警告表示
- 「安全確認後にコピー」など、アプリ内の明示操作に対する確認
- 検出理由と該当する危険カテゴリの表示

## 対象外

- ターミナル、tmux、Zellij、WezTerm等の外部アプリケーションへのキー入力注入
- Ctrl+Vなどのグローバル貼り付け操作のフックまたは遮断
- コマンドの自動実行、自動削除、自動書換え
- AIによるコマンド内容の安全性保証

## 検出候補

検出は警告の補助であり、危険性を確定するものではない。カテゴリごとに検出理由を表示する。

- 複数行の入力（空行だけを除き、実行可能な行が2行以上）
- コマンド連結・パイプ: `;`、`&&`、`||`、`|`
- 破壊的操作の代表例
  - Unix系: `rm -rf`、`sudo rm`、`dd`、`mkfs`
  - Windows: `del /s`、`rmdir /s`、`Remove-Item -Recurse`、`format`
  - Git: `git reset --hard`、`git clean -f`
- ダウンロードした内容を直接実行する構文: `curl ... | sh`、`wget ... | sh` 等
- 権限昇格を伴う構文: `sudo`、`runas` 等

## UI案

1. 履歴項目に警告アイコンまたはリスク種別を表示する。
2. 警告対象をコピーしようとした場合、検出理由と対象テキストのプレビューを表示する。
3. ユーザーは次のいずれかを明示的に選ぶ。
   - コピーする
   - キャンセルする
   - テキストを確認・編集してからコピーする
4. 警告対象ではない通常テキストは、従来どおり確認なしでコピーできる。

## 設定方針

- 初版は安全寄りの既定値で警告を有効にする。
- 自動ブロックは提供しない。
- 将来必要になった場合のみ、カテゴリ別の警告有効／無効設定を追加する。
- 設定を増やしすぎず、少なくとも初版では「警告を有効にする」チェックボックス1つで扱えるようにする。

## 受入条件

- [ ] 複数行テキストを検出し、コピー前に警告できる。
- [ ] 定義済みの危険カテゴリを検出し、検出理由をユーザーへ表示できる。
- [ ] 複数のカテゴリに該当する場合、すべての理由を表示できる。
- [ ] 警告対象でも、ユーザーが明示的に選択すればコピーできる。
- [ ] キャンセル時にクリップボードと履歴内容を変更しない。
- [ ] 通常テキストのコピー操作は従来どおり確認なしで実行できる。
- [ ] 外部アプリのキーボード入力、貼り付け操作、端末設定ファイルを変更しない。
- [ ] 検出ロジックの単体テストとして、複数行・各危険カテゴリ・誤検出しやすい通常文を検証する。
