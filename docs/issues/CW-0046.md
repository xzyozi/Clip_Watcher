# [CW-0046] [architecture] text_workflow の ports.py における具象永続化モジュール (history.py) への直接依存とDIP違反

- **重要度**: Medium
- **関連Issue**: 該当なし

## 1. 概要・背景
抽象インターフェースを定義する ports.py が、SQLite 永続化アダプターである history.py の HistoryEntry に依存しており、依存性逆転の原則に反している。

### 課題詳細 (Problem Detail)
六角形アーキテクチャ（ポート & アダプター）において、ports.py は外部アダプターに要求する抽象インターフェース（ポート）を定義する層である。しかし、7 行目で from src.core.text_workflow.history import HistoryEntry とインポートしており、SQLite 接続を内包する具象アダプター history.py に逆依存している。データモデルである HistoryEntry が具象永続化モジュール内で定義されていることが原因であり、ポート層の独立性とモジュール境界が損なわれている。
