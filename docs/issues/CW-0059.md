# [CW-0059] [security] HTMLEscapePlugin における二方向ヒューリスティック判定の不備によるHTMLサニタイズ（エスケープ）回避リスク

## 0. メタ情報 (Scope & Impact)
- **検出テーマ**: セキュリティ
- **重要度**: Medium
- **関連Issue**: 該当なし
- **起票ステータス**: `stage:ideation` (agys 自律レビュー起票)

## 1. 概要・背景
エスケープとアンエスケープを曖昧なヒューリスティックで自動判別しているため、実体参照を含む悪意ある HTML タグのエスケープが無効化（バイパス）されます。

### 課題詳細 (Problem Detail)
HTMLEscapePlugin.process() は、入力テキスト内に &amp;, &lt;, &gt;, &quot;, &#39; のいずれかが含まれる場合に無条件で html.unescape() を試み、結果に差分があればアンエスケープ後の文字列を返却します。しかし、もし入力文字列に未エスケープの危険な HTML タグと実体参照が混在している場合（例: <script>alert(1)</script>&amp; や <img src=x onerror=alert(1)> &quot;sample&quot;）、エスケープ処理（html.escape）は一切行われず、逆にアンエスケープされた生のスクリプトタグや属性が出力されます。ユーザーが無害化（エスケープ）を期待して本プラグインを適用した際に意図通りのサニタイズが行われないため、貼り付け先や表示先での XSS や HTML インジェクションを誘発するリスクが存在します。
