# [CW-0044] [architecture] EventDispatcher における GUI (messagebox) への直接依存によるレイヤー逆転とスレッド安全性阻害

## 0. メタ情報 (Scope & Impact)
- **検出テーマ**: 関心事の分離（アーキテクチャ境界）
- **重要度**: High
- **関連Issue**: 該当なし
- **起票ステータス**: `stage:ideation` (agys 自律レビュー起票)

## 1. 概要・背景
コア基盤であるイベントディスパッチャが例外ハンドリングで tkinter.messagebox を直接呼び出しており、アーキテクチャ境界違反およびワーカースレッド/テスト環境での障害要因となっている。

### 課題詳細 (Problem Detail)
EventDispatcher は非同期処理やワーカースレッド、ヘッドレス環境などを含むシステム全体で使われるコア基盤である。しかし、リスナー呼び出しの例外捕捉時に log_and_show_error を介して messagebox.showerror を直接実行している。これにより、クリップボード監視やホットキー処理などのワーカースレッドからイベントが発火された際に Tkinter の UI スレッドセーフティ違反が発生するリスクがあるほか、ヘッドレスな単体テストや将来の CLI 実行時にモーダルダイアログで実行が停止・クラッシュする深刻な設計上の歪みを生んでいる。
