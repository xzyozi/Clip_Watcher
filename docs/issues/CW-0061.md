# [CW-0061] [edge_cases] TextWorkflowService._on_task_done における非同期タスク例外発生時の通知喪失とUIハングリスク

## 0. メタ情報 (Scope & Impact)
- **検出テーマ**: エッジケース処理
- **重要度**: High
- **関連Issue**: 該当なし
- **起票ステータス**: `stage:ideation` (agys 自律レビュー起票)

## 1. 概要・背景
非同期ワークフロー実行時に例外が発生した場合、エラーログが記録されるのみでイベント配信やコールバック実行が一切行われず、UIが永久に処理待ち（ハング）状態になる。

### 課題詳細 (Problem Detail)
TextWorkflowService._on_task_done において、future.result() の呼び出しで例外が発生した際に logger.exception を出力してそのまま return している。このため _deliver_result が呼ばれず、EventDispatcher への結果イベント配信や呼び出し元コールバック（callback）の実行が行われない。WorkflowResult には ExecutionStatus.FAILED や error_message といった失敗通知用フィールドが用意されているにもかかわらず活用されておらず、UI側（プログレスバー、スピナー、無効化されたボタン等）が完了・失敗のいずれも検知できずフリーズ状態に陥る。
