# [CW-0028] `test_settings_window_schema.py` の2テストが `tcl_findLibrary` エラーで失敗

### 概要
`tk.Tk()` の生成時に `_tkinter.TclError: invalid command name "tcl_findLibrary"` が発生する。

### 再現手順
```powershell
python -m pytest tests\test_settings_window_schema.py -v
```

### 実際の結果
```
FAILED tests/test_settings_window_schema.py::test_settings_window_schema_composition
FAILED tests/test_settings_window_schema.py::test_settings_window_with_translator_instance
_tkinter.TclError: invalid command name "tcl_findLibrary"
```

### 根本原因
テストコード自体は正しく `root.destroy()` を `finally` で呼んでおり問題ない。エラーはPython/Tclライブラリのパス解決に起因する環境依存の問題で、`TCL_LIBRARY` / `TK_LIBRARY` 環境変数の未設定、またはPythonインストールの破損が疑われる。

### 修正案
コード修正ではなく環境調査が必要。
```powershell
python -c "import tkinter; tkinter.Tk()"
```
を単体で実行し再現するか確認。再現する場合はPythonの再インストール、または `TCL_LIBRARY` 環境変数の見直しを推奨。
