# [CW-0022] アプリ常時起動時にログファイル名の日付と実際のログメッセージのタイムスタンプが乖離する問題

## 概要
アプリケーションを常時起動（日付を跨いで起動）し続けた場合、出力されるログファイル名（日付）と、実際にそのファイルへ書き込まれるログメッセージのタイムスタンプとの間に乖離（ズレ）が発生します。

## 原因分析
現在、`src/utils/logging_config.py` 内の `setup_logging()` において、ログファイル名は以下のように起動時のシステム日付を基に決定されています。

```python
log_file = os.path.join(log_dir, f'clipwatcher_{datetime.now().strftime("%Y%m%d")}.log')
```
