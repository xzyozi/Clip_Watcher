# [CW-0031] [bug] ピン留め履歴の個別ホットキーで自動貼り付けされない

## 概要

ピン留め履歴に個別ホットキーを割り当て、対象アプリケーション上でホットキーを押下しても、自動貼り付けまで実行されません。

## 再現手順

1. クリップボード履歴をピン留めする
2. 対象行を右クリックし、「ホットキーを割り当てる」を選択する
3. 任意のキー組合せ（例: `Ctrl+Alt+1`）を設定する
4. 貼り付け先のアプリケーションをアクティブにする
5. 設定した個別ホットキーを押下する

## 期待する動作

対象のピン留め履歴をクリップボードへ設定し、ホットキー押下時にアクティブだったウィンドウへ `Ctrl+V` を送信して自動貼り付けする。

## 実際の動作

個別ホットキーを押下しても、貼り付け先アプリケーションへの自動貼り付けが実行されない。

以下も確認して追記してください。

- クリップボード内容は対象履歴へ更新されるか
- 通知音は再生されるか
- どの貼り付け先アプリケーションで再現するか
- すべての個別ホットキーで再現するか
- 通常の表示／最小化ホットキーは動作するか
