# [CW-0039] [security] app_main におけるスタートアップバッチ生成時のパスエスケープ不足とPATHハイジャックリスク

## 0. メタ情報 (Scope & Impact)
- **検出テーマ**: セキュリティ
- **重要度**: High
- **関連Issue**: 該当なし
- **起票ステータス**: `stage:ideation` (agys 自律レビュー起票)

## 1. 概要・背景
Windowsスタートアップ登録用バッチファイルの生成において、パスのメタ文字未エスケープによるコマンドインジェクションおよび環境変数PATHに依存した不適切なPythonバイナリ呼び出しのリスクが存在する。

### 課題詳細 (Problem Detail)
MainApplication._manage_startup において、project_root や final_activate_path、main_script_path を f-strings で直接バッチファイル（ClipWatcher.bat）に埋め込んでいます。Windows バッチファイル内では二重引用符があっても & や %、^ などのメタ文字によってコマンドが分割実行されるため、プロジェクト配置パスに特殊文字が含まれる場合にログオン時の意図しないコマンド実行（バッチインジェクション）につながります。さらに、activate.bat が見つからない場合に start "" python "{main_script_path}" と環境変数 PATH の python に依存して起動しているため、カレントディレクトリや PATH 上の悪意ある同名バイナリが実行される DLL/バイナリハイジャックの危険があります。
