# [CW-0076] [enhancement] プラットフォーム非互換フォント設定のサニタイズと安全なフォールバック機構の導入

## 0. メタ情報 (Scope & Impact)
- **影響範囲**: 設定管理（SettingsManager）、設定ウィンドウ（SettingsWindow）、GUIフォント適用
- **既存コードへの依存**: あり（`src/core/config/settings_manager.py` および `src/gui/main_gui.py`）
- **検出テーマ**: プラットフォーム互換性・設定管理・フォントフォールバック
- **重要度**: Low
- **関連Issue**: #197
- **起票ステータス**: `stage:ready`

## 1. 概要・背景
ユーザーが設定ファイルを別環境（Windows から macOS、またはその逆）からインポートした場合や、異なるプラットフォーム間で `settings.json` を共有・同期した場合に、プラットフォーム固有のフォント（例: Windows の `FixedSys` や `MS Gothic`、macOS の `Menlo` や `Monaco`）がそのまま保存されていると、他方の OS 上ではフォントが存在しないため、意図しないフォールバックや設定画面上の不整合が発生する。

### 課題詳細 (Problem Detail)
1. **存在しないフォントファミリの無警告フォールバック**:
   - macOS 上で `FixedSys` や `MS Gothic` などが設定されている場合、Tkinter は例外を出さずにシステム標準フォントへ自動フォールバックするが、ユーザーには「設定したフォントが反映されない」ように見える。
2. **設定画面のフォント選択肢（FONT_PICKER）と現在の設定値の乖離**:
   - 設定画面を開いた際、現在の設定値が `font.families()` に存在しない場合、ドロップダウンに空または不整合な値が表示される。
3. **安全なデフォルトフォントのプラットフォーム別解決**:
   - `TkDefaultFont` 以外のフォントが指定された際、各 OS（Windows / macOS / Linux）で確実に利用可能な汎用フォント（例: 等幅なら `Courier` / `Menlo` / `Consolas`、プロポーショナルなら `Helvetica` / `Arial` / `Meiryo` 等）への安全な解決レイヤーが存在しない。

## 2. 仕様および要求事項 (修正方針の検討)
- [x] **案 1 (推奨・ロード時バリデーションと安全なフォールバック)**:
  1. **フォント検証ユーティリティの導入**:
     - 設定ロード時（またはフォント適用時）に、指定された `font_family` が現在の環境の `font.families()` に存在するかをチェックする。
  2. **非互換フォント検知時の安全なフォールバック**:
     - 指定フォントが存在しない場合は、`TkDefaultFont` または OS 別の標準推奨フォントに安全にフォールバックし、ログにガイダンスを出力する。
  3. **設定画面での適切な選択肢表示**:
     - 存在しないフォントが設定されている場合でも、設定画面で安全に有効なフォントが初期選択されるようにサニタイズする。
- [ ] **案 2 (フォントを固定の数種類のみに制限する)**:
  - ユーザーの自由なフォント選択を過剰に制限してしまうため不採用。
