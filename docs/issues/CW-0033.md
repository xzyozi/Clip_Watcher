# [CW-0033] [保留] 配布物ビルド・クリーン環境・CLI起動をCIで検証する

## 概要
wheel/sdistのビルド、隔離環境へのインストール、CLI起動、および公開InterfaceのimportをCIで検証する。

## 背景
現時点でも `uv build` によるwheel/sdist生成自体は成功するが、wheelには `core`, `db`, `gui` 等がトップレベルパッケージとして含まれる。一方、実装は `src.*` importを前提とするため、リポジトリ外のクリーン環境では `from src...` が解決できない。

これはパッケージ名・入口未確定の問題であり、正しい配布検証は先にパッケージ方針を確定する必要がある。

## 前提条件（未充足のため保留）
- [ ] #94 で実パッケージ名・`[project.scripts]`・import方針が確定している
- [ ] sdist/wheelに含めるパッケージ・アセット・設定ファイルが定義されている

## 実施内容
- wheelとsdistをCIでビルドする
- リポジトリ外の隔離仮想環境へwheelをインストールする
- 公開Interfaceのimportを検証する
- CLIコマンドの存在と起動を検証する
- 必要に応じてGUI起動前のsmoke testを用意する
- sdistからのビルド・インストールも検証する

## 完了条件
- CIでwheel/sdistのビルドが成功する
- クリーン環境でインストール後の公開importが成功する
- CLI起動が検証される
- 配布物に不要なテスト・キャッシュ・開発用ファイルが含まれない
