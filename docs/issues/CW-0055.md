# [CW-0055] [edge_cases] DatabaseManager における DB 格納先親ディレクトリの存在未検証による起動時 OperationalError

## 1. 概要・背景
DatabaseManager 初期化時、指定された db_path の親ディレクトリが存在しない場合に sqlite3.connect がディレクトリを自動生成せず OperationalError で起動に失敗する。

### 課題詳細 (Problem Detail)
DatabaseManager.__init__ では、渡された db_path に対して即座に self._initialize_tables() を呼び出し、内部で `sqlite3.connect(self.db_path)` を実行している。SQLite は指定されたデータベースファイルが存在しない場合は新規作成するが、親ディレクトリが存在しない場合は作成せず `sqlite3.OperationalError: unable to open database file` をスローする。新規インストール環境やポータブル運用、カスタム設定で新規ディレクトリパス（例: data/clipboard.db）が指定された場合、事前に親ディレクトリが存在しないとアプリが初期化フェーズで即座にクラッシュする。
