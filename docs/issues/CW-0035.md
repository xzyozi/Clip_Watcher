# [CW-0035] [feat] URLをページ概要付きMarkdownリンクへ手動変換する

## 背景

URLをクリップボードへコピーした際、ページのタイトルや概要を確認しながら、Markdown形式のリンクとして貼り付けたい。

ただしURLコピー時に自動変換は行わず、履歴項目を選択したユーザーが明示的に変換機能を選ぶ方式とする。

## 目的

履歴内のURLを選択し、ページのhead情報からタイトルと概要を取得して、Markdownリンク形式へ変換できるようにする。

## 実装方針

- TextPluginとして `URL Metadata Link`（名称は調整可）を追加する。
- Formatダイアログからユーザーが明示的に選択して実行する。
- URLコピーの検知時に自動実行しない。
- 外部ライブラリは追加せず、Python標準ライブラリのみを使用する。
  - `urllib.request`
  - `urllib.parse`
  - `html.parser.HTMLParser`
  - `html.unescape`

## 変換後の形式

```md
[ページタイトル](https://example.com/page)
> ページ概要
```

概要が取得できなかった場合は、リンク行のみを出力する。

```md
[ページタイトル](https://example.com/page)
```

## メタデータ取得の優先順位

### タイトル

1. `meta property="og:title"`
2. `<title>`
3. URLのホスト名

### 概要

1. `meta property="og:description"`
2. `meta name="description"`
3. 出力しない

## 受入条件

- [ ] `http` / `https` のURLだけを対象にできる。
- [ ] 履歴項目を選択し、Formatダイアログから明示的に変換を実行できる。
- [ ] URLコピー直後には、自動でネットワークアクセス・変換・クリップボード更新をしない。
- [ ] OGPまたはHTMLのtitle/descriptionからページ情報を取得できる。
- [ ] 取得結果をMarkdownリンク形式に整形できる。
- [ ] タイトル・概要に含まれるMarkdown記号を適切にエスケープできる。
- [ ] タイムアウト、HTTPエラー、非HTMLレスポンス、解析失敗時にアプリが停止しない。
- [ ] 失敗時は履歴の元URLを変更しない。
- [ ] 外部依存パッケージを追加しない。

## 制約・安全対策

- タイムアウト、HTML読込サイズ上限、リダイレクト上限を設ける。
- 初版では `localhost`、プライベートIP、リンクローカルIPおよびリダイレクト後にこれらへ到達するURLを拒否し、意図しないローカルネットワークアクセスを防ぐ。
- JavaScriptで動的に生成されるhead情報や、ログイン・bot対策が必要なページは取得対象外とする。

## 補足

現行のプラグイン設定はGUIタブの表示切替向けであり、TextPluginごとの有効／無効設定はない。初版では設定を増やさず、Formatダイアログからの明示選択だけで提供する。将来、利用頻度が高ければTextPluginの表示／非表示設定を追加する。
