# [CW-0069] [architecture] menu_bar における外部アプリケーションインスタンスへの暗黙の属性注入および深層デメテル則違反

## 0. メタ情報 (Scope & Impact)
- **検出テーマ**: 関心事の分離（アーキテクチャ境界）
- **重要度**: Medium
- **関連Issue**: 該当なし
- **起票ステータス**: `stage:ideation` (agys 自律レビュー起票)

## 1. 概要・背景
create_menu_bar 関数が引数の app_instance に UI 変数を動的代入して暗黙の副作用を与え、かつ深いオブジェクトチェーンを介して子孫コンポーネントの状態を取得している。

### 課題詳細 (Problem Detail)
create_menu_bar 内で app_instance.always_on_top_var = tk.BooleanVar(...) や app_instance.theme_var = tk.StringVar(...) のように、呼び出し元から渡された BaseApplication のインスタンスに対して型定義に存在しない属性を動的に代入（モンキーパッチ）している。また、履歴操作メニュー（L51-54, L60-63）において app_instance.gui.history_component.get_ids_for_indices(app_instance.gui.history_component.get_selected_indices()) と、app -> gui -> history_component の深い探索を行うデメテル則違反（Law of Demeter）が発生している。加えて、一部のコマンドでは EventDispatcher を使っている一方で、他の項目では具象ハンドラを直接呼ぶなど通信経路が不揃いになっている。
